# Task Edge — downloads

Installers for [Task Edge](https://tasked.ge): your tasks and notes in a slim panel on the edge of your screen.

**Get the latest version at [tasked.ge](https://tasked.ge)**, or from
[Releases → Latest](https://github.com/nafiu-dev/task-app-releases/releases/latest).

| Computer | File |
|---|---|
| Windows 10 or later (64-bit) | `TaskEdge-Setup.exe` |
| macOS 12 or later (Apple silicon and Intel) | `TaskEdge.dmg` |

## First launch

- **Windows:** if SmartScreen says "Windows protected your PC", click **More info → Run anyway**.
- **Mac:** open the dmg and drag Task Edge into Applications. If macOS won't open it, go to
  **System Settings → Privacy & Security** and click **Open Anyway**.

## Updates

On Windows, Task Edge updates itself. On Mac, the app tells you when a new version is ready to download.

This repository only holds the release files.
